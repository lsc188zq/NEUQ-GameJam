# NEUQ 游戏部 · Godot 2D RPG 靶场

> 一个**开箱即用**的 Godot 4.7.2 中文 2D 游戏模板。
> 面向"一个月内做出一款 3–10 分钟可玩小游戏"的社团活动。

---

## 这是什么

这是一个 **Godot 2D 俯视角 RPG 的项目模板**。它已经把做小游戏最费时间、最容易踩坑的部分全部准备好了：

- ✅ **中文字体已配好** —— 不会出现 □□□ 豆腐块
- ✅ **8 个插件已打包** —— clone 下来就自带，**你一个都不用装**
- ✅ **Windows / Web 导出已配好** —— 随时能导出发给别人玩
- ✅ **中文文档齐全** —— 从"怎么打开项目"到"怎么加自己的机制"

**题材**：大学校园 · 2D 俯视角
**本期关键词**：**待定**（见 [`docs/07-关键词与规则.md`](docs/07-关键词与规则.md)）

## ⚠️ 先选版本：你要哪个

这个仓库有两条分支，**内容不一样**：

| 分支 | 内容 | 适合谁 |
|---|---|---|
| **`main`**（默认） | **一款完整可通关的校园小游戏** + 框架 + 插件 | **大多数人**。改地图、改台词、改任务，加一个自己的机制 |
| **`blank`** | 只有框架 + 插件 + 字体 + 文档，**没有任何游戏内容** | **会 Godot、想从零搭的人** |

**绝大多数人直接用 `main` 就行，不用管另一条。**

如果你确实想要空白版：

```bash
git clone <这个仓库的地址>
cd <仓库目录>
git checkout blank
```

> ⚠️ GitHub 的 "Use this template" 按钮**只能拿到默认分支（`main`）**。想要空白版必须自己 clone 后切分支。

## 环境要求

### Godot 4.7.2 标准版 —— 版本必须一致，没有例外

| | |
|---|---|
| **版本** | **Godot 4.7.2**（写死。用别的版本打开会导致场景文件被静默迁移） |
| **构建** | **标准版**，不是 Mono / .NET 版 |
| **下载** | https://godotengine.org/download/windows/ |

**为什么不能换版本**：对话插件 Dialogue Manager 4 硬性要求 Godot 4.6+；而且 Godot 的 4.x 小版本之间，场景文件会**静默迁移**——用 4.7 打开过的项目再用 4.6 打开会出各种诡异问题，而且**不会报错**。

### 中国大陆网络

`git clone` 在大多数情况下可用。如果卡住：

1. **推荐**：装 [Watt Toolkit（原 Steam++）](https://steampp.net)，勾选 "GitHub 加速"
2. **备选**：用镜像前缀 `https://ghfast.top/`，例如
   ```
   git clone https://ghfast.top/https://github.com/lsc188zq/NEUQ-GameJam
   ```

⚠️ `raw.githubusercontent.com` 在大陆**完全不通**。已失效的镜像：`gh-proxy.com`、`hub.gitmirror.com`。

## 快速开始

```
1. 下载并安装 Godot 4.7.2 标准版
2. clone 这个仓库（或用 "Use this template" 建自己的仓库）
3. 用 Godot 打开项目文件夹（选 project.godot）
4. 等首次导入完成（左下角进度条走完，第一次会慢一点）
5. 按 F5
```

**第一次打开时要注意**：

- 插件已经全部打包好了，**不要自己去装任何插件**
- `addons/` 里有 10 个文件夹但插件列表只有 8 个 —— **这是正常的**，原因见 [`docs/04-插件说明.md`](docs/04-插件说明.md)
- 如果编辑器报一堆看不懂的错：**关掉 Godot，删掉 `.godot/` 文件夹，重新打开**（那只是缓存，删了不丢任何东西）

### 导出（做给别人才需要）

> 编辑器 → **编辑器 → 管理导出模板** → 装 **Windows** 和 **Web** 两个平台

**⚠️ 别点"下载全部"，那有 1.22 GB。** 只勾 Windows 和 Web 就够（约 110 MB）。

详见 [`docs/05-导出指南.md`](docs/05-导出指南.md)。

## 目录结构

```
NEUQ-GameJam/
├── content/              ★ 主要改这里：对话、任务
│   ├── dialogues/        .dialogue 台词文件（改台词）
│   └── quests/           .tres 任务资源（改任务）
├── scenes/               场景
│   ├── world/            地图
│   ├── player/           玩家
│   ├── npc/              NPC
│   └── ui/               界面
├── scripts/              代码
│   ├── autoload/         全局单例
│   ├── components/       可复用组件
│   └── hooks/            ★ 扩展点：加自己的机制改这里
├── assets/               图片、音频
├── fonts/                中文字体（立夏黑体）+ 许可证
├── addons/               插件（已打包，别动）
├── docs/                 中文文档
└── wip/                  原始素材暂存区（Godot 看不见，可选）
```

### ⚠️ 三条铁律

**1. 绝对不要用文件管理器移动或重命名项目里的文件**

Godot 的场景文件（`.tscn`）里存的是**文件路径**。用文件管理器挪个位置，所有引用它的地方**全部失效**——而且**不会立刻报错**，可能几天后才发现。

> **正确做法**：在 Godot 左下角的 **FileSystem 面板**里右键 → 移动/复制。

**2. 绝对不要提交 `.godot/` 文件夹**

那是 Godot 的导入缓存，每台机器都不一样。`.gitignore` 已经配好了，**不要去动**。

**3. 不要修改 `addons/` 里的文件，也不要删里面的 `LICENSE`**

插件都是 MIT 协议，允许我们打包分发，**唯一要求就是保留许可证文本**。

## 内置插件

| 插件 | 干什么 |
|---|---|
| **Dialogue Manager** | 对话系统。写 `.dialogue` 文件就能做分支对话，**改台词不用写代码** |
| **QuestSystem 2** | 任务系统（接受 / 推进 / 完成） |
| **Godot State Charts** | NPC 行为状态机（待机 / 巡逻 / 对话中），可视化编辑 |
| **Maaack 菜单套件** | 主菜单、选项、暂停、制作人员名单、场景加载、背景音乐、界面音效 |
| **Godot AI** | 让 AI 助手直接操作 Godot 编辑器（**需要付费的 MCP 客户端，多数人用不了，不用管它**） |
| `plugin_updater` / `clean_copy_examples` | ⬜ **未启用**。只是给菜单插件提供全局类，删了菜单会坏 |

**每个插件的详细用法 → [`docs/04-插件说明.md`](docs/04-插件说明.md)**
