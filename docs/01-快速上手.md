# 01 · 快速上手

> 目标：**从零到按 F5 能跑起来**，大约 20 分钟。
> 遇到卡住的地方，先看最后一节，再看 [`06-常见问题.md`](06-常见问题.md)。

---

## 第 0 步 · 装 Godot 4.7.2（约 10 分钟）

**版本必须完全一致，没有例外。**

1. 打开 https://godotengine.org/download/windows/
2. 下载 **Godot Engine** —— ⚠️ **不要下带 .NET / Mono 的那个**
3. 下下来是个 zip，**解压到一个固定位置**，比如 `D:\Tools\Godot_v4.7.2\`
4. 双击里面的 `.exe` 就能用——**Godot 不需要安装**，解压就能跑

**⚠️ 不要放在桌面或下载文件夹**，容易误删，而且路径里有中文可能出问题。

> **为什么必须是 4.7.2**：项目里用的对话插件硬性要求 Godot 4.6+；而且 Godot 的 4.x 小版本之间会**静默迁移场景文件**——用 4.7 打开过的项目再用 4.6 打开会出各种诡异问题，**而且不报错**。

---

## 第 1 步 · 拿到项目

### 方式 A：建自己的仓库（推荐）

1. 打开模板仓库页面
2. 点绿色的 **"Use this template"** → **Create a new repository**
3. 填仓库名，选 Public，创建
4. 然后 clone 你自己的仓库：

```bash
git clone https://github.com/你的用户名/你的仓库名
```

### 方式 B：直接 clone 模板仓库

```bash
git clone https://github.com/lsc188zq/NEUQ-GameJam
```

**如果你在大陆网络下 clone 卡住**，用镜像前缀：

```bash
git clone https://ghfast.top/https://github.com/lsc188zq/NEUQ-GameJam
```

或者装 [Watt Toolkit（原 Steam++）](https://steampp.net) 并勾选 "GitHub 加速"。

---

## 第 2 步 · 用 Godot 打开项目

1. 打开 Godot 4.7.2
2. 在项目管理器里点 **导入（Import）**
3. 浏览到你 clone 下来的**文件夹**，选中里面的 **`project.godot`**
4. 点 **导入并编辑（Import & Edit）**

**第一次打开会慢一点**——Godot 要导入所有素材和插件。左下角有进度条，等它走完。

### ⚠️ 第一次打开时你可能会怀疑出问题了

| 现象 | 是否正常 |
|---|---|
| 导入要等十几秒到一分钟 | ✅ 正常，第一次都要等 |
| 插件列表里有 8 个插件、但 `addons/` 里有 10 个文件夹 | ✅ **正常**，原因见 [`04-插件说明.md`](04-插件说明.md) |
| 下方多出一个 "Godot AI" 面板 | ✅ 正常，不用管它 |
| 提示"检测到脚本改动，是否重新加载" | ✅ 点是 |
| 一堆红字报错 | ❌ **不正常**，看下一节 |

---

## 第 3 步 · 按 F5 跑起来

直接按 **F5**（或点右上角的 ▶ 按钮）。

**第一次跑会问你"选择主场景"**——如果弹出来了，选项目里指定的主场景即可。

---

## 第 4 步 · 认识四个地方

打开项目后，你只需要认识 Godot 界面的这四个区域：

```
┌─────────────┬───────────────────────┬─────────────┐
│  ① 场景      │  ② 主视图             │  ③ 检查器    │
│   （树状）    │   （画东西的地方）      │  （改属性）   │
│             │                       │             │
├─────────────┴───────────────────────┴─────────────┤
│  ④ FileSystem（文件面板）                          │
│     ← 项目里所有文件都在这，移动/重命名文件只能在这里做  │
└───────────────────────────────────────────────────┘
```

- **① 场景（Scene）**：显示当前场景里有哪些节点，谁是谁的爹
- **② 主视图**：2D 视图，摆东西的地方
- **③ 检查器（Inspector）**：选中一个节点，这里改它的属性
- **④ FileSystem**：项目文件浏览器。**⚠️ 移动/重命名文件只能用这里，不能用 Windows 资源管理器**

---

## 第 5 步 · 动手改点东西试试

先随便改一个不用写代码的东西，确认你掌握了工作流。

**改一句对话**：

1. 在 ④ FileSystem 里找到 `content/dialogues/` 文件夹
2. 双击里面的 `.dialogue` 文件
3. 找到 `角色名: 台词` 那一行，把台词改掉
4. **Ctrl+S 保存**
5. 按 **F5** 运行，走到那个 NPC 面前按 **E**

**改完发现没用？** 检查是不是保存了（文件名旁边有个小圆点表示没保存）。

## 移动 / 重命名文件

# ⚠️ 只能用 Godot 的 FileSystem 面板

**绝对不要用 Windows 资源管理器移动或重命名项目里的文件。**

**为什么**：Godot 的场景文件（`.tscn`）里存的**不是文件内容，是文件路径**。你用资源管理器挪一下，所有引用它的地方**全部失效**——而且**当时不会报错**，可能几天后你运行到某个分支时才发现。

**正确做法**：在 ④ FileSystem 面板里右键那个文件 → **移动/复制（Move/Duplicate）**。Godot 会自动更新所有引用。

## 出问题了？

### 先试这个（能解决 80% 的怪问题）

> **关掉 Godot → 删掉项目里的 `.godot/` 文件夹 → 重新打开**

`.godot/` 只是导入缓存，**删了不会丢任何东西**，Godot 会重新生成。

### 然后查这个顺序

1. **你的 Godot 是不是 4.7.2？** 版本不对是最常见的原因
2. **你是不是用资源管理器移动过文件？**（见上）
3. **插件是不是被禁用了？** 项目设置 → 插件 → 看该启用的有没有勾
4. **中文是不是变成 □□□ 了？** 看 [`06-常见问题.md`](06-常见问题.md) 的"显示类"

### 还不行，去群里问

**贴这三样**：

1. **完整报错文字**（能复制的文字，**不是截图**）
2. **你刚才做了什么**（越具体越好）
3. `git log --oneline -3` 的输出

**不要只发一张截图问"这是为什么"** —— 没人能回答。
