## 什么是"加一个机制"

靶场里你会看到一个文件：

```
scripts/hooks/game_hooks.gd
```

里面有 **5 个空函数**，每个都带注释说明什么时候会被调用。**在那里写 20–40 行代码，就能给游戏加一个属于自己的机制。**

```gdscript
## 【钩子 1】玩家做了某件事时被调用
## 用途示例：让 NPC 记住玩家做过什么（"回声"关键词）
## 改这里，就能让世界对玩家的行为做出反应
func on_player_action(action_name: String) -> void:
    pass  # ← 在这里写你的代码
```

**这就是你要的"轻量代码的创造体验"**——不用从零搭系统，在一个明确的点上改，立刻能看到效果。

## 本文档将会包含的机制配方

每个配方都是**完整可抄的 20–40 行代码 + 逐行讲解**：

| 配方 | 说明 | 难度 |
|---|---|---|
| NPC 复读玩家上一次做的事 | 钩子 1 记录 + 修改对话 | ★ |
| 玩家走过的地方留下痕迹 | 钩子 1 + 生成节点 | ★★ |
| 同一个 NPC 第二次对话内容不同 | 钩子 2 + GameState 计数 | ★ |
| 计时压力 | 钩子 5 + 倒计时 UI | ★★ |
| 重复同一个动作会累积效果 | 钩子 1 + 计数器 | ★★ |

## 在补全之前，你可以先想清楚这个

**写不出下面这句话，就说明范围太大了，先砍：**

> 玩家做 **\_\_\_** → 于是 **\_\_\_** → 然后 **\_\_\_** → 回到第一步

举例：

> 玩家**和 NPC 对话** → 于是 **NPC 记住了这句话** → 然后**玩家再遇到他时，他会重复这句话** → 回到第一步

**能写出这句话，机制就成立了。** 写不出来就说明你在想一个"系统"而不是一个"机制"——系统一个月做不完。
