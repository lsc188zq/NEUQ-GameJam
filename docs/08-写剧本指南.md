# 08 · 写剧本指南

> 用 Dialogue Manager 写对话。**改台词、加分支、让对话记住玩家做过的事，都不用写代码。**
>
> 剧本文件放在 `content/dialogues/`，扩展名是 `.dialogue`。

---

## 一、最小的剧本

```dialogue
~ start

学长: 你好。

=> END
```

三个概念就够：

| 写法 | 含义 |
|---|---|
| `~ start` | **段落开头**。一个剧本可以有多个段落，`start` 是默认入口 |
| `学长: 你好。` | **一句台词**。冒号前是角色名，后面是内容 |
| `=> END` | **结束对话** |

**段落之间用空行分隔**，同一个段落里的连续台词不用空行。

---

## 二、语法速查表

| 写法 | 作用 |
|---|---|
| `~ 段落名` | 段落开头 |
| `角色: 台词` | 一句台词 |
| `- 选项文字` | 分支选项 |
| `- 选项文字 => 目标` | 选了跳转到目标段落 |
| `=> 目标` | 跳转到另一个段落 |
| `=> END` | 结束对话 |
| `$> 代码` | 执行一行 GDScript |
| `if 条件:` / `elif` / `else:` | 根据状态说不同的话 |
| `- 选项 [if 条件 /]` | 这个选项只在条件下出现 |
| `[[A|B|C]]` | 随机挑一句 |
| `[#标签=值]` | 给这句台词加标签（如语音） |
| `[img]路径[/img]` | 在台词里插图片 |
| `# 注释` | 不显示也不执行 |
| `using 全局对象名` | 引入一个全局对象 |

---

## 三、逐项详解

### 1. 段落（`~`）

把剧本切成一块一块，每块有个名字，可以互相跳转。

```dialogue
~ start

学长: 你好。

=> 打招呼

~ 打招呼

学长: 今天天气不错。
=> END
```

**入口段落**：如果代码里没指定从哪开始，默认找 `start`。

### 2. 跳转（`=>`）

```dialogue
=> 某个段落名      # 跳到那个段落
=> END            # 结束对话
```

拼写错误时会在导入时报“**标题未定义**”（见第六节）。

### 3. 分支选项（`-`）

```dialogue
~ start

学长: 你好，是新来的吧？

- 我是来报到的。 => baodao
- 你在忙什么？ => mang


~ baodao

学长: 报到在行政楼。
=> END


~ mang

学长: 我在等代码编译。
=> END
```

**最后一定要有个 `=> END`**，否则玩家选了之后对话不会结束。

### 4. 根据状态说不同的话（`if` / `else`）

```dialogue
~ start

if GameState.get_flag("见过学长"):
	学长: 又见面了。
else:
	学长: 你好，是新来的吧？
	$> GameState.set_flag("见过学长", true)

=> END
```

读法：
- **第一次对话** → 开关没设过 → 说“你好”，然后**把开关设上**
- **第二次对话** → 开关已经是 true → 说“又见面了”

**⚠️ 缩进必须用 Tab，不能用空格。** 这是最容易出错的地方。

### 5. 选项上的条件（`[if ... /]`）

```dialogue
学长: 有事吗？

- 没事。 => END
- 我找到钥匙了。 [if GameState.get_flag("有钥匙") /] => 交钥匙
```

**注意结尾那个 `/`，不能漏。** 漏了会报语法错误。

### 6. 在对话中间执行代码（`$>`）

```dialogue
学长: 好，我给你登记一下。

$> GameState.set_flag("已报到", true)

学长: 登记完了。
=> END
```

**这是对话和游戏逻辑连接的地方**——接任务、给道具、开门，都靠它。

### 7. 随机台词（`[[...]]`）

```dialogue
学长: [[今天天气不错。|你来了啊。|又见面了。]]
```

每次对话随机挑一句。

### 8. 注释（`#`）

```dialogue
# 这一行不会显示，也不会执行
学长: 你好。
```

写给自己看的笔记，比如“这句以后要改”。

### 9. 标签（`[#...]`）

```dialogue
学长: 你好。 [#voice=res://assets/audio/hello.ogg]
```

给单句台词加附加信息。目前项目里用得上的是 `voice`（播放配音）。

### 10. 引入全局对象（`using`）

```dialogue
using GameState

~ start

if GameState.get_flag("某某"):
```

**但本项目已经把 `GameState` 注册成快捷方式了**，所以**不用写 `using GameState`**，直接用就行。

## 四、⚠️ 三个必须记住的坑

### 坑 1：`=> END` 必须大写

```dialogue
=> END      ✅
=> end      ❌ 报「标题未定义」
```

**写小写不会告诉你“大小写错了”**，而是报“标题未定义”，让你去找一个根本不存在的段落。
**实测确认过**：同一份内容，小写失败、大写成功。

### 坑 2：段落名用拼音，别用中文

```dialogue
~ baodao        ✅
~ 报到          ⚠️ 理论合法，但容易匹配不上
```

段落名虽然**语法上允许中文**，但编码、复制粘贴、输入法任何一个环节出错，
就可能出现“**看着一样但匹配不上**”，报的错还是“标题未定义”。

**用拼音，零风险。** 台词正文用中文完全没问题。

### 坑 3：缩进必须用 Tab

```dialogue
if 条件:
→ 学长: 这句话缩进了一级
else:
→ 学长: 另一句
```

（只能用 Tab，不能用 4 个空格）

**一句话记法**：**关键字大写、段落名拼音、缩进用 Tab。**

## 五、让对话“记住”玩家

这是最好用、也最容易做出好效果的一件事。

**原理**：对话里可以读写 `GameState`（全局状态），而 `GameState` 里的东西**换场景不会丢**。

### 例子：NPC 记得你见过他没有

```dialogue
~ start

if GameState.get_flag("见过学长"):
	学长: 又见面了。
else:
	学长: 你好，是新来的吧？
	$> GameState.set_flag("见过学长", true)

=> END
```

### 例子：根据任务进度说不同的话

```dialogue
~ start

if GameState.completed_quests.has("找猫"):
	学长: 那只猫找到了？厉害啊。
else:
	学长: 听说教学楼那边有只猫不见了。

=> END
```

**`GameState` 的完整可用内容**见 `scripts/autoload/game_state.gd`（里面每个变量都有注释）。

## 六、错误对照表

| 报错 | 真正的原因 | 怎么办 |
|---|---|---|
| **标题未定义** | ① `=> 目标` 找不到对应段落<br>② `=> END` 写成了小写<br>③ 段落名两边不匹配 | 检查拼写；确认 `END` 是大写；段落名改用拼音 |
| **标题名不能为空** | 写了 `~` 但后面没名字 | 补上段落名 |
| **标题名不能重复** | 两个段落用了同一个名字 | 改名 |
| **标题不能以数字开始** | 如 `~ 1开始` | 换个名字 |
| **那一段没有内容** | 段落里只有注释或空白 | 删掉这个空段落，或加点台词 |
| **`.dialogue` 双击打不开** | 文件里有编译错误，**打不开就看不到错误**——这是个死循环 | 见下面的解法 |

### ⚠️ “双击打不开” 的死循环怎么破

Dialogue Manager 有个很坑的行为：**文件有错时导入会静默失败，导致文件根本打不开，而你又需要打开它才能看到错在哪。**

**解法（官方给的绕过办法）：**

1. 用记事本打开这个 `.dialogue`，**把内容全删掉，存成空文件**（或者只留 `~ start` 和 `=> END`）
2. 回 Godot 等它导入完
3. 双击打开它 —— 这次能打开了
4. 把内容粘回去，保存
5. **这回错误会显示在 DM 编辑器里**

**或者更简单**：直接把内容换成第一节那个最小剧本，能打开了再一点点加回来，加到哪一步报错就知道了。

## 七、一个完整的例子

把上面所有东西串起来：

```dialogue
using GameState


~ start

if GameState.get_flag("已报到"):
	学长: 又见面了。今天熟悉校园了吗？
	- 差不多了。 => END
	- 还没。 => 指路
else:
	学长: 你好，是新来的吧？
	- 我是来报到的。 => 指路
	- 你在忙什么？ => 忙


~ 指路

学长: 行政楼出这个门往右走。
学长: 对了，公告栏上有很多社团招新的消息。
$> GameState.set_flag("已报到", true)
=> END


~ 忙

学长: 我在等代码编译。
学长: 已经二十分钟了。
学长: [[或许它已经挂了。|我开始怀疑人生了。|算了，先不管了。]]
=> END
```

**这个剧本里有什么：**
- 段落 3 个（`start` / `指路` / `忙`）
- 分支 5 个
- 条件判断 1 处
- 改游戏状态 1 处
- 随机台词 1 处

## 八、怎么在游戏里用上

剧本写好了，得让 NPC 知道该用哪个。

1. 打开 NPC 的场景（如 `scenes/npc/npc_green.tscn`）
2. 选中根节点
3. 右边检查器里找 **`Dialogue`**
4. 把 `.dialogue` 文件**从 FileSystem 面板拖进那个框**
5. 保存

**就这一步。** 剩下全归插件管：弹出对话框、逐字显示、按键翻页、显示选项、结束关闭。

### 多个 NPC 用不同剧本

**每个 NPC 拖不同的 `.dialogue` 就行**，不用改任何代码。

### 一个 NPC 根据情况说不同的剧本

以后如果需要，可以通过 `$>` 改 NPC 的 `dialogue` 变量。**现在用不上。**
