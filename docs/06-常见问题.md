## 一、环境类

### Q：我用哪个版本的 Godot？

**Godot 4.7.2，标准版。没有例外。**

- 版本必须和全社团一致。**用 4.6 或 4.8 打开这个项目会导致场景文件被静默迁移**，之后别人再打开就会出各种诡异问题
- **不要用 Mono 版**（文件名带 `mono` 或 `.NET` 的那个）。我们全用 GDScript，Mono 版只会带来麻烦
- 下载：https://godotengine.org/download/windows/ （选 **Godot Engine**，不是 .NET）

### Q：为什么我导不出游戏？

因为你还没装**导出模板**。

> 编辑器菜单 → **编辑器 → 管理导出模板** → 下载并安装

**⚠️ 别点"下载全部"——那有 1.22 GB。** Godot 4.7 支持按平台下载：只勾 **Windows Desktop** 就够（约 100 MB）。要做网页版再勾 **Web**（约 12 MB）。

模板版本必须和编辑器版本**完全一致**。

### Q：我下载很慢 / 连不上 GitHub

大陆网络的现实情况：

| 地址 | 情况 |
|---|---|
| `raw.githubusercontent.com` | **完全不通** |
| `github.com` 网页 | 经常超时 |
| `git clone` | **一般能用** |
| GitHub 下载文件 | 慢，但能下 |

**加速办法（按推荐顺序）：**

1. **Watt Toolkit（原 Steam++）** —— 装上就行，勾选"GitHub 加速"。对国内学生最省事。下载：https://steampp.net
2. **用 `ghfast.top` 镜像**。在 GitHub 链接前面加上 `https://ghfast.top/` 就行。例如：
   ```
   # 原始
   https://github.com/xxx/yyy/archive/refs/heads/main.zip
   # 走镜像
   https://ghfast.top/https://github.com/xxx/yyy/archive/refs/heads/main.zip
   ```
   实测比直连快约 4 倍。
3. **让会长把文件传到群文件** —— 兜底方案，永远有效。

**已经挂掉的镜像，别再用**：`gh-proxy.com`、`hub.gitmirror.com`。

### Q：Godot 编辑器能打开插件商店吗？

能。**新商店（Asset Store）自己托管文件，不走 GitHub**，国内可以正常用。

但注意：**这个项目已经把需要的插件全部打包在 `addons/` 里了，你一个都不用装。**

## 二、文件操作类

### Q：⚠️ 我能用文件管理器移动项目里的文件吗？

# 不能。

**这是新手最容易踩、后果最严重的坑。**

Godot 的场景文件（`.tscn`）里存的**不是文件内容，而是文件路径**。你用文件管理器（或资源管理器）把 `player.tscn` 挪个位置，Godot 里所有引用它的地方**全都失效**——而且**不会立刻报错**，可能过几天你运行到某个分支时才发现。

**正确做法**：
> 在 Godot 左下角的 **FileSystem 面板**里右键 → **移动/复制（Move/Duplicate）**

在面板里移动，Godot 会自动更新所有引用。

### Q：`.godot/` 文件夹是什么？要提交吗？

**# 绝对不要提交。**

`.godot/` 是 Godot 的**导入缓存**——每次你改图片、改场景，它都会重新生成。它：

- 体积大
- 每台机器上都不一样
- 提交了会导致**持续的冲突和无意义的改动**

`.gitignore` 里已经写好了，**你不要去动它**。

> 顺带一提：如果编辑器报了一堆莫名其妙的错，**删掉整个 `.godot/` 文件夹然后重开 Godot** 通常能解决。这不会丢任何东西，它只是缓存。

### Q：我把大文件（PSD、素材包）放哪？

**不要放进项目里。**

原始素材（PSD、Aseprite 源文件、下载来的素材压缩包）放在**项目文件夹外面**，比如 `D:\Projects\NEUQ-GameJam-artwork\`。

原因：Godot 会尝试导入项目文件夹里的所有东西，PSD 会让你的仓库瞬间膨胀到几百 MB。

如果一定要放项目里，放进带 `.gdignore` 的文件夹（见下）。

### Q：`.gdignore` 是什么？怎么用？

在文件夹里放一个**空的、名字就叫 `.gdignore`** 的文件，Godot 就会**完全跳过这个文件夹**——不扫描、不导入、不在 FileSystem 面板显示。

**规则：**
- 文件名必须是 `.gdignore`，**内容留空**
- **放在那个文件夹"里面"**，不是外面
- 放在项目根目录**不生效**（实测过）

**这个项目里怎么用：**

| 文件夹 | 要放吗 |
|---|---|
| `docs/` | ✅ 要（纯文档，游戏不读） |
| `wip/` | ✅ 要（原始素材） |
| `content/dialogues/`、`content/quests/` | ❌ **绝对不能放**！这些是游戏运行时必须读的 |

## 三、显示类

### Q：中文全变成 □□□ 豆腐块怎么办？

**先分清是哪种情况：**

| 情况 | 原因 | 解决 |
|---|---|---|
| **编辑器里和运行都豆腐块** | 默认字体没设或者字体没加载 | 见下 |
| **Windows 运行正常，导出 Web 后豆腐块** | **字体没打包进项目** | 见下 |

**原因**：Godot 默认字体是 Open Sans，**不含任何中文字**。Godot 会自动拿**系统字体**兜底 CJK，但这个兜底**只支持 Windows/macOS/Linux/Android/iOS，不支持 Web**。

所以现象是：**在 Windows 上按 F5 跑，中文一切正常；一导出网页版，中文全变方块。**

**这个项目已经打包好了中文字体**（`fonts/SumrSans.ttf`），默认字体也已经设好。如果你还是看到豆腐块：

1. 检查 `fonts/SumrSans.ttf` 还在不在
2. 检查 **项目设置 → GUI → Theme → Custom Font** 有没有指向它
3. 关掉 Godot，删 `.godot/`，重开

**不要用"系统字体"方案**（`SystemFont`），它在网页版上无效。

### Q：像素画显示得很糊 / 有毛边

**项目设置 → 渲染 → 纹理 → 画布纹理 → 默认纹理过滤**，改成 **Nearest**。

（如果你用的不是像素画，保持默认即可。）

### Q：游戏画面比例不对 / 有黑边

项目设计分辨率是 **1280×720**，拉伸模式 `canvas_items` + `expand`。正常情况应该自动适配任何屏幕。

如果你改了这两个设置又不知道改回去，去 **项目设置 → 显示 → 窗口** 恢复。

## 四、插件类

### Q：插件怎么装？

**不用装。** 项目里 `addons/` 已经打包好了：

| 插件 | 干什么 |
|---|---|
| `dialogue_manager` | 对话系统 |
| `quest_system` | 任务系统 |
| `godot_state_charts` | NPC 行为状态机 |
| `godot_ai` | AI 辅助（**需要付费的 MCP 客户端，多数人用不了，不用管它**） |
| `maaacks_menus_template` | 主菜单 / 选项 / 暂停 / 名单 |
| `maaacks_scene_loader` | 场景切换 + 加载画面 |
| `maaacks_music_controller` | 背景音乐 |
| `maaacks_ui_sound_controller` | 界面音效 |
| `plugin_updater` | ⬜ **未启用**。只是给菜单插件提供全局类，删了菜单会坏 |
| `clean_copy_examples` | ⬜ **未启用**。同上 |

**⚠️ `addons/` 里有 10 个文件夹但插件列表只有 8 个——这是正常的。** 后两个不能删也不能启用，原因见 [`04-插件说明.md`](04-插件说明.md) 开头。

**每个插件是干什么的、怎么用 → 看 [`04-插件说明.md`](04-插件说明.md)。**

clone 下来就自带。**不要去动 `addons/` 里的文件。**

### Q：插件功能用不了 / 报错说找不到 XXX

去 **项目设置 → 插件**，看对应插件的 **Enable** 有没有勾上。

如果勾了还不行，取消勾选 → 重开 Godot → 重新勾选。

### Q：`addons/` 里的 `LICENSE` 文件能删吗？

**不能。** `addons/` 里的插件都是 MIT 协议，MIT 允许我们打包分发，**唯一的要求就是保留版权声明和许可证文本**。删了就是侵权。同理 `fonts/LICENSE.txt` 也不能删。

## 五、编辑器抽风类

### Q：编辑器报了一堆看不懂的错 / 场景里东西突然不见了 / 各种诡异问题

**按这个顺序试：**

1. **关掉 Godot → 删掉 `.godot/` 文件夹 → 重开 Godot**
   （最常见，能解决 80% 的怪问题。`.godot/` 只是缓存，删了不丢东西）

2. **检查你最近是不是用文件管理器移动过文件**（见上文，这是第二大原因）

3. **检查 Godot 版本**是不是 4.7.2

4. `git status` 看看你改了什么，`git checkout .` 回滚到上次提交

5. 还不行 → 群里问，**贴报错文字 + 你刚才做了什么**

### Q：我改了一大堆东西全乱了，怎么回到之前的状态？

```bash
git status              # 看看改了哪些文件
git checkout .          # 放弃所有未提交的改动（⚠️ 不可撤销）
```

**所以：多提交。** 每完成一个小功能就 commit 一次。这样任何时候都能退回去。

## 六、还是解决不了？

在群里问的时候，**请贴这三样**：

1. **完整报错文字**（不是截图，是能复制的文字）
2. **你刚才做了什么**（越具体越好）
3. **`git log --oneline -3` 的输出**（你改到哪一步了）

**不要只发一张截图问"这是为什么"** —— 没人能回答。
