# 05 · 导出指南

> 把游戏变成**别人能运行的东西**。
> **⚠️ 不要等到最后一天才做这件事。** 导出链路的问题越早发现越好。

---

## 零、先装导出模板（只做一次）

Godot 编辑器本身**不能**直接导出——它需要一个叫**导出模板**的东西（预先编译好的各平台引擎本体）。

> **编辑器菜单 → 编辑器 → 管理导出模板（Editor → Manage Export Templates）**

会弹出一个对话框。**⚠️ 千万别点"下载全部"，那有 1.22 GB。**

Godot 4.7 支持**按平台下载**，只勾这两个：

```
☑ Windows Desktop (x86_64)     约 100 MB
☑ Web                          约 12 MB
☐ 其它全部不勾
```

然后点 **安装所选模板（Install Selected Templates）**。

**下载源是 `godotengine.org`，不是 GitHub**，国内一般能直接下。

**装好的标志**：

```
%APPDATA%\Godot\export_templates\4.7.2.stable\
```

里面有 `windows_release_x86_64.exe`、`web_nothreads_release.zip` 这些文件（一共十几个，约 288 MB）。

> ⚠️ 如果只有"下载并安装"一个按钮、没法选平台，那它会下全部 1.22 GB。实在下不动就找会长要（他会把文件放群文件）。

---

## 一、导出 Windows 版（最常用，优先做这个）

### 步骤

1. **项目 → 导出（Project → Export）**
2. 点 **添加（Add...）** → 选 **Windows Desktop**
3. 底部有两个路径：
   - **导出路径（Export Path）**：`.exe` 放哪
   - 旁边的文件夹图标：`.pck` 放哪
   - **建议都放在同一个新建的空文件夹里**
4. 点 **导出项目（Export Project）**

### ⚠️ 会生成两个文件，缺一不可

```
我的游戏.exe      ← 启动器
我的游戏.pck      ← 游戏数据
```

**两个必须放在一起。** 只把 `.exe` 发给别人，他打不开。

**所以发的时候要打包成 zip**，不要单独发 exe。

### 建议：zip 里附一个 `读我.txt`

Godot 导出的 exe **没有代码签名**，别人双击时 Windows 的 SmartScreen **必然会弹警告**（"Windows 已保护你的电脑"）。

在 zip 里附一个说明，避免别人以为你发了病毒：

```
【怎么运行】
1. 解压整个文件夹（不要只解压 exe）
2. 双击 我的游戏.exe
3. 如果 Windows 弹出蓝色警告窗口：
   点「更多信息」→「仍要运行」
   这是正常的——Godot 导出的游戏都没有买代码签名证书
【怎么玩】
WASD 移动，E 交互，ESC 暂停
```

### 分享给同学

- **推荐**：打成 zip 发**群文件**
- 网盘也行，但下载速度看网盘

**⚠️ 不要发 GitHub Release 链接**——`raw.githubusercontent.com` 在大陆完全不通，下载 release 文件也很慢。

## 二、导出网页版（Web）

### 步骤

1. **项目 → 导出 → 添加 → Web**
2. ⚠️ **检查这两个选项，必须都是关闭的**：

```
☐ Thread Support        ← 必须不勾！
☐ Extensions Support    ← 必须不勾！
```

**为什么**：勾了之后，网页版就需要服务器返回 `COOP`/`COEP` 响应头才能运行，而**绝大多数免费托管（包括 GitHub Pages）不能设响应头**，游戏就打不开。

**保持不勾**（默认就是不勾），导出的就是单线程版本，**任何静态托管都能直接跑**。

3. 点 **导出项目** → 会生成一个文件夹（`index.html` + `.wasm` + `.pck` 等）

### 托管到哪

| 平台 | 大陆访问 | 说明 |
|---|---|---|
| **GitHub Pages** | ⚠️ 慢/经常打不开 | 零配置能用，但给国内同学看体验差 |
| **Cloudflare Pages** | ⚠️ 不稳定 | 免费，通常能开 |
| 腾讯 EdgeOne Pages / 阿里云 ESA | ✅ 较快 | 可能要备案 |
| **itch.io** | ⚠️ 时好时坏 | 专门托管游戏，体验好 |
| Netlify / Vercel | ❌ 慢 | 不推荐 |

**⚠️ 重要**：如果只是**展示日当场演示**，**用 Windows 版最稳**。

网页版适合**发给同学自己玩**。但你要提前测试——**在你自己手机上打开试试**，有些手机浏览器跑不动。

### 网页版最容易出的两个问题

| 症状 | 原因 | 解决 |
|---|---|---|
| 页面一直转圈，游戏不出来 | 服务器没返回 COOP/COEP 头 | 重新导出，**确认 Thread Support 没勾** |
| 中文全变成 □□□ | **字体没打包进项目** | 本项目已内置字体。如果你自己加过字体，确认它真的被打包了 |

**⚠️ 中文字体那条特别隐蔽**：Godot 会自动用**系统字体**兜底中文，但这个兜底**不支持 Web**。所以现象是——**你在电脑上按 F5 跑，中文一切正常；一导出网页版，中文全变方块。**

## 三、常见导出问题

### Q：点导出报 "No export template found" / "找不到导出模板"

**导出模板没装，或者版本对不上。**

- 4.7.2 的编辑器**只能**用 4.7.2 的模板
- 去 **编辑器 → 管理导出模板** 检查
- 装完需要**重启 Godot**

### Q：导出的 exe 打不开 / 一闪而过

- **是不是只拷了 `.exe` 没拷 `.pck`？**（最常见）
- Windows 版本选对了吗？现在基本都是 `x86_64`
- 试着导一个 **调试版**（把导出对话框里的"调试"选项打开），这样能看到报错

### Q：别人电脑上打不开，我这能开

- 他的电脑可能是 32 位系统（你导出的是 x86_64）
- 显卡驱动太老——**项目用的是 GL Compatibility 渲染器**，已经是最兼容的选择了
- 文件没传完整（zip 损坏）

### Q：导出后中文变方块，但我电脑上是好的

见上面 Web 那节。**这是"系统字体兜底不支持 Web"导致的**，必须把字体打包进项目。

### Q：导出的文件好大

- 正常现象。Godot 引擎本身就有几十 MB
- 可以做"导出时压缩"（导出对话框里有个选项），能小一些
- 别为此删素材，不值当

### Q：我想导出成手机能玩的

**本期不做这个。** 安卓导出要配 JDK、Android SDK，坑很深，一个月内不值得。

## 四、演示日建议

**如果你要上台演示：**

1. **提前在自己的电脑上跑一遍**，别到台上才第一次运行
2. **准备好 Windows 版**放在桌面，网页版当备选
3. **关掉微信、QQ 的弹窗**——它们会抢焦点，游戏会暂停
4. **调好音量**，别开场炸麦
5. **准备一段 60 秒的录屏**——万一现场电脑有问题，直接放录屏

**⚠️ 提前去演示场地试一次**，特别是投影仪的分辨率和缩放比例——有些投影会把窗口挤变形。
