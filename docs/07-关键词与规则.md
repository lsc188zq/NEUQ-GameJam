## 关键词是什么，不是什么

这是最容易搞混的地方：

| | 是什么 | 例子 |
|---|---|---|
| **关键词** | **创作约束**。所有组都必须围绕它做设计，是"命题作文"的题 | 回声、潮汐、信号 |
| **题材 / 设定** | 故事发生在哪儿、长什么样 | **大学校园**（本期已定） |

**两者是叠加的，不是二选一。** 比如：

> **关键词「回声」+ 设定「大学校园」** = 做"校园里的回声"——NPC 会重复你做过的事，你在校园里留下的痕迹被别人继承。

## 本期限制条件

| 限制 | 说明 |
|---|---|
| **场景数** | **3 个以内**（一张地图算 1 个场景） |
| **NPC 数** | **2 个** |
| **核心机制** | **1 个**。一句话说不清就砍 |
| **流程长度** | **3–10 分钟**能通关 |
| **题材** | 大学校园，2D 俯视角 |
| **引擎** | Godot 4.7.2，不能换 |

### 为什么要限制

**因为这些限制是保护你的。** 一个月的时间，做 3 个场景、2 个 NPC、1 个机制，和一个 100 分钟的 RPG，前者能做完，后者做不完。

**做完的小游戏 > 做不完的杰作。**

---

## 关键词的判定标准

会长选关键词时，用这四条筛：

1. **一句话能说清**
2. **能想出 3 种以上可实现机制**（想不出 3 种说明太窄）
3. **不依赖难获取的素材**（比如"赛博朋克"就需要大量特殊美术）
4. **和"校园"能自然结合**

## 拿到关键词之后怎么做

1. **先想机制，再想故事。** 先用一句话说出"这个关键词在**玩法上**是什么"，再去编剧情
2. **写下你的核心循环一句话**：
   > 玩家做 ___ → 于是 ___ → 然后 ___ → 回到第一步
   >
   > **写不出来，说明范围太大，砍。**
3. **去 [`03-加机制指南.md`](03-加机制指南.md)** 看现成的机制配方，挑一个改
4. **把关键词写进你的游戏**——不一定要出现在台词里，但要能让人玩完感觉到
