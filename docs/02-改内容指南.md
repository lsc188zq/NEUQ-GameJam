## 本文档将会覆盖什么

靶场完成后，这里会有**零代码或极少代码**就能完成的修改，每一项都配有具体步骤：

| 你想改什么 | 会写在这里 |
|---|---|
| **换地图** | 怎么在 Godot 里铺瓦片、怎么设置碰撞、怎么调整相机边界 |
| **换角色图** | 怎么替换玩家/NPC 的精灵图，怎么对齐帧序列 |
| **改台词** | `.dialogue` 文件的语法：分支、条件、随机台词 |
| **改任务** | 怎么在检查器里改任务名、条件、奖励，不用写代码 |
| **改标题 / 结算文字** | 在哪个场景改 |
| **换中文字体** | 怎么把字体设成项目默认（以及为什么 Web 版必须打包字体） |
| **换音乐和音效** | 用 Maaack 的音乐/音效控制器，不用写代码 |
| **调画面** | 分辨率、纹理过滤（像素画必须设 Nearest） |

## ⚠️ 无论改什么，这三条都不能违反

**1. 移动或重命名文件，只能用 Godot 的 FileSystem 面板**

用 Windows 资源管理器挪文件，`.tscn` 里存的路径会全部失效，**而且不会立刻报错**。

**2. 不要动 `addons/` 里的文件**

那是插件本体，改了会出各种怪问题，而且删掉里面的 `LICENSE` 就是侵权。

**3. 改完立刻按 F5 跑一遍**

**一次只改一个东西，改完马上运行确认。** 攒一堆一起改，出错了你都不知道是哪个改坏的。
