## 一、加家具

### ① 用现成的（最常用）

1. 打开 **`scenes/world/world.tscn`**
2. 场景树里**右键 `Classroom` 下面的 `Furniture` 节点** → **实例化子场景**
3. 选一个现成的：

```
scenes/furniture/chair_wood.tscn    木椅
scenes/furniture/desk_wood.tscn     课桌
scenes/furniture/bookshelf.tscn     书架
scenes/furniture/plant_palm.tscn    盆栽棕榈
scenes/furniture/books.tscn         书堆
scenes/furniture/door.tscn          门
```

4. 拖到想要的位置 → **完事**

**贴图、碰撞、互动区全都自动带上了**，你只需要摆位置。

### ② 用一张没用过的贴图

比如你想摆一台 `assets/sprites/furniture/storage/cabinet_wood_05.png`：

1. 右键 `Furniture` → **实例化子场景** → 选 **`furniture_item.tscn`**（最基础的那个）
2. 选中它 → 检查器最上面 **`Texture`** 那一栏 → **把 PNG 拖进去**
3. **碰撞盒和互动区会自动跟着贴图尺寸重算**

**就这两步。** `assets/sprites/furniture/` 下面有 269 张图，按类别分了 13 个文件夹。

### ③ 做「一类」新家具（一批共用同一份剧本）

比如你要 8 把蓝色的椅子，它们共用一份台词：

1. FileSystem 面板里**右键 `chair_wood.tscn`** → **新建继承场景**
2. 改它的 `Texture` 和 `Dialogue`
3. 存成 `chair_blue.tscn`
4. 以后 8 把椅子全都拖 `chair_blue.tscn`

**改剧本 = 打开 `chair_blue.tscn` 改一次，8 把全变。**

### ⚠️ 两条最容易犯的错

**1. 绝对不要把 PNG 直接拖进场景**

那样建出来的是一个**纯 `Sprite2D`**：

| | 纯 `Sprite2D`（拖 PNG） | `FurnitureItem`（拖场景） |
|---|---|---|
| 原点在脚下 | ❌ 在图片正中心 | ✅ |
| 和角色的前后遮挡 | ❌ **反的** | ✅ |
| 挡不挡路 | ❌ 没有碰撞 | ✅ |
| 玩家能按 E 说话 | ❌ | ✅ |

**记住：拖场景，不拖图片。**

**2. 家具必须放在 `Classroom/Furniture` 底下**

那个节点开着 `y_sort_enabled`。**放到别处，遮挡关系就废了。**

## 三、调家具

选中任意一件家具，检查器里就三样东西：

| 属性 | 作用 | 什么时候改 |
|---|---|---|
| **`Texture`** | 贴图 | 换外观 |
| **`Blocks Movement`** | 勾 = 挡路；**不勾 = 纯装饰** | 地毯、地上的贴纸、墙上的画**要取消勾选** |
| **`Footprint Height`** | 碰撞盒**高度**（像素）。**0 = 自动**（底边 10px） | 见下 |
| **`Dialogue`** | 拖个 `.dialogue` 进来 | 想让它按 E 有反应 |

### `Footprint Height` 怎么调

**碰撞盒 = 宽度跟贴图一样，高度 = 这个值，对齐到底边中点。**

| 现象 | 怎么办 |
|---|---|
| 贴着家具走不进去，感觉"太胖" | **调小** |
| 人能从家具中间穿过去，感觉"太虚" | **调大** |
| 纯装饰 | 直接关掉 `Blocks Movement` |

**⚠️ 怎么看碰撞盒在哪——这是唯一可靠的办法：**

> **跑游戏时，菜单 → 调试 → 显示碰撞形状**（Debug → Visible Collision Shapes）

**编辑器的 2D 视图里看不到**家具实例内部的碰撞形状，所以别在那儿找。

### 想让形状不是长方形（比如 L 形桌子）

得打开 `scenes/furniture/furniture_item.tscn` 手动改 `CollisionShape2D`。**但注意脚本每次刷新都会重新生成形状覆盖它**——真要自定义得先把那行去掉。

## 四、做一个任务

### 五步

#### ① 做一个任务资源

> FileSystem 面板 → 右键 `content/quests/` 里**现成的 `.tres`** → **复制（Duplicate）** → 改名

**为什么复制而不是新建**：新建要走"新建资源"对话框选类，复制快得多，而且不会漏字段。

双击打开，在检查器里填：

| 字段 | 说明 |
|---|---|
| **`id`** | 一个不重复的数字（只用于区分，随便填） |
| **`quest_name`** | **任务名 —— 这就是任务的唯一标识**，剧本里按它找 |
| **`quest_description`** | 描述（暂时不显示，留着给以后的任务列表用） |
| **`quest_objective`** | **目标 —— HUD 上显示的那一行** |

**然后二选一：**

| 用哪个类 | 还要填 | 什么时候完成 |
|---|---|---|
| **`SimpleQuest`** | `complete_flag` | 那个**开关**变成 true |
| **`CountQuest`** | `counter_key` + `required` | 那个**计数**达到 `required` |

#### ② 登记到 QuestBook

> 打开 **`scenes/quest_book.tscn`** → 选中根节点 `QuestBook` → **把新 `.tres` 拖进 `all_quests` 数组**

**⚠️ 这一步忘了 = 任务在游戏里根本不存在。**

**怎么知道忘了没有**：游戏启动时输出面板会打一行——

```
【QuestBook】已登记 3 个任务：去见学长, 帮学长找钥匙, 你新加的这个
```

**你的任务名不在里面，就是没登记上。**

#### ③ 让它能完成

```
SimpleQuest：在某个剧本里写   $> GameState.set_flag("你填的那个开关名")
CountQuest ：在某个地方写     $> GameState.bump("你填的那个计数器名")
```

#### ④ 从对话里接任务

```
$> QuestBook.start("你填的任务名")
```

#### ⑤ 剧本里判断任务状态

```
[if QuestBook.is_active("任务名") /]     ← 正在进行中
[if QuestBook.is_done("任务名") /]       ← 已经完成
```

### 完整例子：做一个「收集 3 个螺丝」的任务

```
① 复制 content/quests/q_find_books.tres → 改名 q_fix_pc.tres
   双击，填：
     id              = 4
     quest_name      = 修好那台破电脑      ← 记住这个字符串
     quest_objective = 收集 3 个螺丝
     counter_key     = 螺丝
     required        = 3

② 打开 scenes/quest_book.tscn，把 q_fix_pc.tres 拖进 all_quests

③ 在某个剧本里写：
     $> QuestBook.start("修好那台破电脑")

④ 在 3 个地方写：
     $> GameState.bump("螺丝")

⑤ 第 3 个螺丝一捡到 → HUD 自动变成「✓ 修好那台破电脑　完成」
```

**全程没写一行代码。**

### ⚠️ 三个最容易踩的坑

| 坑 | 症状 | 怎么发现 |
|---|---|---|
| **忘了拖进 `all_quests`** | 游戏里完全找不到这任务 | 输出面板的"已登记 N 个任务"里没有它 |
| **任务名打错一个字** | 静默不触发 | 输出面板警告 `【QuestBook】找不到叫「xxx」的任务` |
| **改了 `.dialogue` 没生效** | 游戏里还是旧台词 | 要在 Godot 里让 FileSystem 重新扫描（`Project → Reload Current Project`） |

## 五、加物品

**"物品"和"计数"在本项目里是同一个东西**——一个名字 + 一个数字：

```gdscript
GameState.counters = { "钥匙": 1, "零件": 3, "见过的人数": 2 }
```

### 加一个

在剧本里写：

```
$> GameState.bump("螺丝")          ← 加 1 个
$> GameState.bump("螺丝", 5)       ← 加 5 个
```

**右上角的背包会自动多出一行**，你什么都不用做。

### 用掉

```
$> GameState.spend("螺丝")         ← 扣 1 个（不够就什么都不做）
```

**数量归零的物品会自动从背包上消失。**

### 判断有几个

```
[if GameState.get_count("螺丝") >= 3 /]
```

### ⚠️ 三条要知道的

1. **物品没有图标、没有说明** —— 只有名字和数量。以后要图标再说。
2. **名字就是 ID** —— **打错一个字就是另一个物品**（`"钥匙"` 和 `"钥是"` 是两个不同的东西，而且**不报错**）。建议复制粘贴，别手打。
3. **"计数"和"物品"是一回事** —— `"螺丝"` 是物品，`"见过的人数"` 是计数，系统看来完全一样。**所以 `CountQuest` 一个类就能做"收集 5 个"和"和 3 个人说过话"两种任务。**

## 六、改地图

### 铺瓦片

1. 打开 `scenes/world/world.tscn`
2. 在场景树里选中 **`Classroom` → `Ground`**（地板）或 **`Walls`**（墙）
3. 编辑器底部会出现 **TileMap** 面板 → 选中要画的瓦片 → 直接在视口里点

**⚠️ 图层别搞混：**

| 图层 | 画什么 | `z_index` | 有碰撞吗 |
|---|---|---|---|
| **`Ground`** | 地板 | -10 | ❌ 不产生 |
| **`Walls`** | 墙 | -5 | ✅ 有（挡人） |
| **`Props`** | 要**和角色互相遮挡**的装饰 | 0 | ❌ 不产生 |

**为什么 `Props` 单独一层**：`Ground` 和 `Walls` 被压到了背景层，**它们不参与前后遮挡排序**。要让某个瓦片"挡住角色"（比如地上立着的箱子），**画在 `Props` 里**。

### 相机边界

**不用管，自动的。**

`scenes/world/world.gd` 会读**地板层画过的范围**，自动设好相机边界。你把地板铺到哪，镜头就跟到哪，**不用改任何代码**。

**验证**：跑游戏时输出面板会打一行

```
【world.gd】相机边界已设为：(-224, -128) 到 (224, 128)
```

## ⚠️ 无论改什么，这三条都不能违反

**1. 移动或重命名文件，只能用 Godot 的 FileSystem 面板**

用 Windows 资源管理器挪文件，`.tscn` 里存的路径会全部失效，**而且不会立刻报错**。

**2. 不要动 `addons/` 里的文件**

那是插件本体，改了会出各种怪问题，而且删掉里面的 `LICENSE` 就是侵权。

**3. 改完立刻按 F5 跑一遍**

**一次只改一个东西，改完马上运行确认。** 攒一堆一起改，出错了你都不知道是哪个改坏的。
